# GUI 操作说明

## 创建格式模板

“创建模板”支持导入 TXT、Markdown、DOCX 格式要求或 JSON 规范。先本地解析，或填写 AI 地址、模型和 Key 后发送对话；每次 AI 回复都会更新完整 JSON 草稿。API Key 不保存到设置文件。发送内容包括格式要求、草稿及本次对话，只有点击发送才调用外部服务。

编辑 `spec` 中的规则，核对 `evidence` 的原文来源并处理 `issues`；有未解决问题时不能生成。点击“校验并查看完整规范”可查看展开默认值后的规则。“保存协议草稿”允许保存尚未解决的问题，方便下次继续编辑。填写尚不存在的目录，确认核对后生成模板及样张；生成成功会自动选中 `spec.json` 用于后续转换。

选择格式协议时，“Word 模板”应留空，图表题注、表格样式和公式编号由协议控制。普通用户可先使用仓库 `tests/fixtures` 示例；字段含义和本版限制见 [格式规范与模板生成](format-spec.md)。模板/AI 任务期间禁用重复提交，取消等待当前请求返回或超时；关闭运行中的窗口仍会等待清理。

运行 `python run_gui.py` 或安装后执行 `markdown2word`。需要 pywebview 和 Microsoft Edge WebView2 Runtime；无需 Tkinter、Node.js 或前端开发服务器。

若窗口启动失败，弹窗会显示具体原因、当前 Python 和启动日志位置：`%LOCALAPPDATA%\Markdown2Word\logs\startup.log`。只有确认初始化后的渲染器不可用时才提示检查 WebView2，其他启动异常不会统一归为运行时缺失。

界面包含“选择文档”“转换偏好”和结果卡片。大窗口为双栏，小窗口自动改为单栏，底部操作与状态保持可见。右上角按钮切换深浅主题，偏好自动保存。

选择 Markdown 后自动填写同名 DOCX 输出路径；手工指定输出后更换源文件不会覆盖它。模板留空使用内置模板，路径可以通过原生文件对话框选择或手工填写。当前输入文档和输出路径不跨会话保存。

使用分段选择器切换 Word 原生公式 / MathType 公式。原生模式无需 Office；MathType 模式需要 Microsoft Word、MathType 和加载项，支持行间公式右编号。编号的章节形式当前仅支持单章。

正文参考文献上标默认关闭，启用后处理数字方括号引用，排除公式、代码和参考文献列表。允许覆盖默认关闭，新结果通过检查才会替换旧成品。

展开“高级设置”可调整自动图表题注、模板表格、Word 自动启动、Visio、超时和 Python/Pandoc 路径，并检测环境。环境检测不启动 Office，诊断结果显示在日志中。

点击“开始转换”，结果卡片显示任务状态。成功后可打开文档或所在文件夹，失败原因和警告直接显示。日志可手动展开，出现警告/错误时自动展开；拖动日志区域下边缘可调整高度。查看旧日志不会强制跳回底部，滚到底部后恢复跟随。“复制”按钮通过系统剪贴板复制完整日志，文件不可用时复制当前缓存；也可以选中文字后按 Ctrl+C。完整日志按钮打开 `%LOCALAPPDATA%\Markdown2Word\logs\latest.log`。后续转换或环境检测会覆盖这份日志，排查前请先保存。

保存时若目标文件被占用或没有写入权限，工具会短暂重试，仍无法覆盖时在同目录另存带唯一名称的 DOCX。原目录无法写入时，改存到日志目录下的 `recovered` 文件夹。另存成功时显示警告，结果卡片及打开按钮指向实际成品，原文件保持不变。

转换时设置不可修改。取消先请求后台清理；10 秒未响应时由核心终止后台进程树。关闭正在运行的窗口会先询问是否清理退出，等待完成后才关闭。失败和取消保留已有成品，临时文件自动清理。转换期间不要操作 Word；若有模态对话框，需要关闭后再重试。

Markdown 引用的本地图片会自动嵌入，缺失时显示警告。MathType 公式中的 tag 会自动清理，代码保留为带底纹的可编辑文本。上述转换逻辑与无 GUI 命令行共用。

对于首尾分隔符独占一行的明确 `$$` 公式块，工具会兼容内部空白行，并在日志中提示原始行号；分隔符未配对、空公式或未识别的公式会报错。超链接统一显示为蓝色并保留跳转。源 Markdown 不会被修改。
